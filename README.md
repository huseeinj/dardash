# الدردشة العربية — Flutter MVP

تطبيق مراسلات عربي RTL يعمل على Android و iPhone، مصمم ليكون أساساً لتطبيقك.

## المزايا المضمنة في التصميم
- تسجيل/إنشاء حساب بالبريد الإلكتروني وكلمة المرور
- اسم مستخدم من 1 إلى 4 أحرف/أرقام إنجليزية
- محادثات خاصة
- مجموعات خاصة
- مدير المجموعة يستطيع طرد/حظر الأعضاء
- بحث عن المستخدمين
- قائمة أشخاص عشوائية
- صورة شخصية مع نظام بلاغات
- نظام Coins
- أسعار افتراضية:
  - صورة: 50 Coins
  - فيديو: 100 Coins
  - Plus: 2000 Coins
  - شراء Plus مباشرة: 10 USD
  - 50 Coins: 1 USD
  - 100 Coins: 2 USD
- هدايا قابلة للتحويل إلى Coins
- Plus يجعل المزايا المدفوعة مجانية
- لوحة إدارة للمالك
- تصميم RTL ووضع ليلي
- طبقة جاهزة لربط Supabase

## مهم قبل النشر
هذا المشروع هو أساس قابل للتشغيل والتطوير، وليس بديلاً عن إعداد حسابات المتاجر أو مفاتيح Supabase أو بوابة الدفع.

### الدفع عبر Zain Cash
تم تصميم التطبيق ليعرض رقم الدفع الذي أدخلته في إعدادات التطبيق، لكن الدفع الحقيقي يجب ربطه بواجهة Zain Cash الرسمية أو بنظام تحقق يدوي. لا تضع مفاتيح API داخل تطبيق الهاتف.

للدفع اليدوي يمكن:
1. المستخدم يختار الباقة.
2. التطبيق يعرض رقم Zain Cash الخاص بالمتجر.
3. المستخدم يرسل المبلغ من تطبيق Zain Cash.
4. يدخل رقم العملية/الإيصال.
5. لوحة الإدارة تتحقق وتضيف Coins أو Plus.

## التشغيل
1. ثبّت Flutter.
2. نفّذ:
   flutter pub get
3. أنشئ مشروع Supabase.
4. نفّذ ملف `supabase/schema.sql`.
5. انسخ قيم Supabase إلى `lib/config.dart`.
6. شغّل:
   flutter run
